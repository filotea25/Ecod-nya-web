# 🌿 EcoDünya

EcoDünya is a sustainable web project focused on environmental awareness and eco-friendly solutions.

## 🌍 About the project

This website promotes conscious consumption and environmental protection through:

- Sustainable products section
- Plastic footprint simulator
- Informative pages about ocean protection
- Modern eco-friendly UI design

## 🛠 Technologies Used

- HTML5
- Tailwind CSS
- Responsive Design
- Modern UI & Microinteractions
